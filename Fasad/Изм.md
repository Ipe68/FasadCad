# Изменения программы Fasad

## 05.11.2026 — упрощён запуск и сохранение проектов

- Основной запуск — `New project.py` (команда AutoCAD `ФАСАД` / `FASAD`).
- Убрана привязка к чертежу `Чертеж1.dwg`: программа работает с активной вкладкой AutoCAD.
- Имя проекта определяется именем активного DWG без расширения.

- Удалён отдельный сценарий `edit project.py` и соответствующая команда редактирования из `Фасад.lsp`.
- Проверка активного чертежа после окна исходных данных теперь использует полный путь, чтобы не продолжить построение, если пользователь переключился на другую вкладку.

Проверены синтаксис Python, поиск проекта и защита перезаписи. Работа сохранения и перезаписи в реальном AutoCAD требует отдельной проверки.

## 12.11.2026 — разделение марки при замене одного ригеля

- `locate` больше не объединяет выбранные пролёты с одинаковой маркой: каждый выбор хранит свой
  `(y, x_лев, x_прав)`. `plan_edits` сравнивает выбранные пролёты со всеми пролётами марки.
- Если выбраны не все одинаковые ригели, старая марка остаётся у невыбранных, а для выбранных создаётся
  новая: например один из двух `R1_в` становится `R2_в`. Если выбраны оба — марка не разделяется.
- В строку `ФАСАД_ПРОФИЛЬ` добавлен скрытый атрибут **ПРОЛЕТ**; `ObjectParams.пролеты` закрепляет марку
  за конкретными пролётами. Без этого новая марка терялась бы при следующем перестроении. Старые таблицы
  без ПРОЛЕТ работают по-прежнему. Стойки имеют независимые S1/S2/... и разделения не требуют.
- **MARK_S и MARK_R снова видимы**: убраны из слоёв выключения и явно включаются в `finish_code`.
- Проверено в AutoCAD на одном верхнем левом ригеле: R1_в → R2_в, только его артикул менялся на КПС 921;
  верхний правый оставался R1_в со своим прежним артикулом. После повторного перестроения R2_в и его
  пролёт сохранились. Тестовая марка затем удалена, пользовательские артикулы оставлены. В чертеже видимы
  3 марки стоек и 6 марок ригелей.
