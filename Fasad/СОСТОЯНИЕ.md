# Программа Fasad — что сделано (на 06.11.2026)

## 1. Что делает программа

По осям в активном чертеже AutoCAD строит витражи СИАЛ КП50К:
- фасад: стойки, ригели, крышки, прижимы, термовставки, доборные, закладные, подкладки, марки, размеры;
- сечения **Б-Б** (горизонтальное, по всем стойкам) и **А-А** (вертикальное, по первому пролёту без двери) с выносками;
- спецификацию в Excel и раскрой хлыстов в папке проекта.

Оси: стойки — слой `OSs`, ригели — `OSr`, фальш-ригели — `OSf`, только линии без шифров.

## 2. Как запускать

| Что | Как |
|---|---|
| Построить фасад и сохранить проект | в AutoCAD команда **ФАСАД** (или `FASAD`); либо `py "New project.py"` в `C:\cad\Fasad`. Используется активный чертёж. Имя проекта берётся из имени активного DWG, имя Excel — из поля «Название» окна исходных данных |
| Пересобрать старую базу из каталога | команда **ФАСАДБАЗА** или `py Собрать_базу.py` (нужна только как запасной путь, см. п. 4) |
| Заменить профиль отдельных марок | команда **ЗАМЕНАПРОФИЛЯ** (REPLACEPROFILE): выбор полилиний на фасаде → окно с допустимыми профилями по каждой марке → правка в таблицу профилей и перестроение |
| Проверить библиотеку узлов | `py Сверка_узлов.py` |
| Снять привязки и нарисовать атлас | `py Привязки.py` |

Команды AutoCAD — файл `C:\cad\Fasad\Фасад.lsp`. Чтобы грузились всегда: APPLOAD → «Автозагрузка» → добавить `Фасад.lsp`.
При запуске активный DWG сверяется с проектами в `C:\cad\Projects`. Если найден одноимённый проект, программа запрашивает подтверждение перезаписи; иначе создаёт новый. После успешного построения DWG, Excel и файлы настроек сохраняются в папке проекта. Связь с AutoCAD — через `mcp_dispatch.lsp`
(`C:\Users\ipe_A\autocad-mcp\lisp-code`), команда загружает его сама.
В окне исходных данных есть чекбокс «Считать статику» и кнопка «Расчёт нагрузок» — расчёт профилей
по нагрузкам программой Lora, см. п. 10.

## 3. Сечения — откуда берутся (главное изменение 01.11.2026)

**Главный источник — библиотека готовых узлов, нарисованная пользователем:**
`C:\cad\Kat sial\Каталог КП50К_ACAD_02_2025\Блоки основные профили КП50Л.dxf`
(путь записан в `systems\КП50К.toml`, раздел `["сечение"]`, ключ `"библиотека"`).

В файле: ~213 блоков профилей и комплектующих + **285 узлов** — все варианты комплектации и толщины 4–58 мм,
стойки и ригели, средние и крайние (с вариантами доборных). Все строки таблицы комплектации покрыты.

Как программа использует узел:
| Шаг | Что делает |
|---|---|
| Выбор | по варианту, толщине, стойка/ригель, средний/крайний; у крайнего — по набору доборных из таблицы периметра (с выбором из пары «А (Б)» по полю «Доборные») |
| Профиль | заменяется на выбранный в исходных данных (узел привязан к носику профиля, глубина профиля не важна) |
| Положение | узел ставится носиком на ось; лево/право, низ/верх — зеркалом |
| Верхний ригель | опорная подкладка не ставится (она только под стеклом) |
| Стекло | по формуле стеклопакета; без формулы — прямоугольник по толщине заполнения (раньше без формулы стекло не рисовалось) |
| Выноски | раскладка полок — по образцу пользователя (`КП50К_выноски.json`), начало выноски — на настоящей детали |
| Блоки | при построении блоки узлов загружаются в чертёж; старые одноимённые блоки переименовываются в «имя (старый N)» |

Узла нет в библиотеке → **черновик по привязкам** + замечание «ПРОВЕРИТЬ» (сейчас таких нет).
Нет библиотеки совсем → старый путь: база из каталога (лист 03).

Файл читается около минуты только после изменения; копия чтения — `systems\КП50К_библиотека.json`.

### Как добавить узел
1. Нарисовать в файле библиотеки из блоков (или скопировать похожий и поправить): профиль и детали — вставки блоков с именем-артикулом,
   стекло — прямоугольник на слое, начинающемся со `Stek`, фиксирующие подкладки — контур на слое `Подкладки`.
2. Над узлом слева — подпись строки, например «Т50   24 мм». От соседних узлов — не ближе 250 мм.
3. Сохранить как DXF с тем же именем, запустить `py Сверка_узлов.py`.
4. Новый набор доборных — сверка сама предложит внести его в `КП50К_периметр.csv` (y/n, страница каталога; копия — `.csv.bak`).
   Новый вариант/толщину в `КП50К_комплектация.csv` — вписать вручную.

## 4. Привязки (запасной путь и проверка)

Сняты с образцов пользователя: в узле две опорные линии —
- **носик профиля**: уплотнитель на профиле, опорная подкладка (внутренний край 5,0 мм от оси ригеля), начало пакета доборных, внутренняя грань стекла (−11,4);
- **наружная грань стекла**: уплотнитель прижима, прижим, крышка, головка винта (своя глубина у каждого прижима); термовставка упирается в прижим.

Нахлёст в пакете доборных: профиль на профиль 3 мм, профиль на уплотнитель 4 мм, уплотнитель на профиль 2 мм.
Код: `fasad\rules.py`, данные: `systems\КП50К_привязки.json`, атлас: `выход\атлас_привязки\`.

## 5. Правила конструктора (важнее каталога)

- Заполнение 4–10 мм: от оси стойки/ригеля до кромки стекла **8,5 мм** (у остальных 12).
- Опорные подкладки — **только на ригелях** под пакет. На стойках в каталоге местами нарисованы опорные — опечатка.
- Крышка ригеля — **КП45309**.
- 50 мм Adifoam: термовставка **Adifoam 530.082**, винт **ВС 5,5х60**.
- Adifoam 530.121 укорачивается по перфорации: блоки «Adifoam 530.121», «… 40», «… 49» по толщинам.
- «СП 32» = «Спейсер 32».
- Тяжёлые подкладки КПС 846 (40–48 мм) / КПС 1126 (52–58 мм): для толщины 50 мм не предусмотрены.
  Стекло > 200 кг при толщине без тяжёлого варианта → программа предлагает сменить толщину пакета.

## 10. Статика (расчёт нагрузок, подключено 05.11.2026)

По нагрузкам профили считает программа **Lora** (`C:\cad\Lora_2_2`, профили — `data\profiles.xlsx`).
В окне «Исходные данные» чекбокс **«Считать статику»** блокирует все поля, кроме «Название объекта»
и самих «считать статику» + **«Расчёт нагрузок»**. Кнопка запускает Лору отдельным процессом
(`main.py --фасад <проект>\статика.json`). В Лоре расчёт как обычно; результат уходит в Фасад
кнопкой **«Экспорт в FS»** или сам при закрытии окна (если расчёт выполнялся).

Обмен — файл `статика.json` в папке проекта: Фасад пишет блок «вход» (название, толщина стекла —
сумма толщин стёкол из формулы пакета: 6-16-6-16-6 → 18 мм, не заполнение;
`система_лора` из `КП50К.toml` → список «SIAL KP50K» выбирается в Лоре сам;
«размеры» — из осей текущего витража: `b1` приведённая ширина грузовой площади (взвешена по высотам
ячеек), `b2` длина расчётного ригеля = max шаг стоек − 20, `l1`/`l2` высоты пакета по большей/меньшей
стороне расчётного ригеля − 24 (у крайнего ригеля 0), `h_m` высота стойки), Лора дописывает
«результат» (выбранные стойка/ригель: артикул, глубина, моменты, ok; вес и толщина стекла;
нагрузки). При повторном открытии проекта фильтры восстанавливаются из файла.

По «результату» в окне исходных данных:
- в списках «Стойка»/«Ригель» остаются только профили глубиной не меньше выбранных в Лоре;
- выбранные в Лоре стойка/ригель подставляются в поля витража;
- тяжёлое стекло (правило «тяжелый» в карточке) → только вариант «Тяжелые КПС 846» (≤ 48 мм)
  или «Тяжелые КПС 1126» (> 48 мм);
- строка результата под объектом; «ПРОВЕРИТЬ» — профиль не проходит по моментам;
- ригель — ещё и по креплению: по весу стекла берутся требуемые отверстия закладной (с/бс/б),
  из списка убираются ригели без такой закладной (под болты «б» — только от 124,5 мм: КПС 344,
  926, 586, 345, 475, 636, 718, 801/829); если Лора подобрала непригодный ригель — предупреждение
  «по прочности проходит, но применить нельзя».

Код: `fasad\lora_link.py` (запуск/обмен/фильтры + `cell_geometry` - размеры по осям), `fasad\dialog.py`,
`fasad\run.py`; в Лоре — `main.py` (режим `--фасад`, приём «входа» и «размеров») и кнопка `pushButton_8`.
**Лора запоминает сеанс**: при закрытии поля ввода сохраняются в `Lora_2_2\save_data\последний_сеанс.json`
и восстанавливаются при любом следующем запуске (в т.ч. из Фасада — его данные имеют приоритет).
Настройки — `["статика"]` в `КП50К.toml` (`путь`, `питон`, `система_лора`).
